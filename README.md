# 一、执行摘要（投资人版）

## 一句话定位

**智享家庭大屏** = 家庭AI OS × 社区消费平台  
把中国4亿家庭的电视大屏，升级为社区数字消费入口。

## 核心数据（18个月目标）

| 指标 | 数据 |
|------|------|
| 目标家庭 | 50万户 |
| 年收入预期 | 2.7亿元 |
| 单家庭年价值（LTV） | 540元 |
| 天使轮融资需求 | 500万元 |
| A轮估值目标 | 1.5亿元 |

## 为什么现在是最好的时机

1. **AI能力成本断崖式下降**：GPT API成本2024年下降90%，AI功能已可低成本集成
2. **家庭大屏复苏**：中国智能电视装机量超6亿台，但内容生态贫乏
3. **社区商业数字化空白**：微信生态未能覆盖"电视+社区"这一场景
4. **老龄化加速**：2025年中国60岁以上人口2.8亿，家庭陪伴刚需

## 商业模式（三重收入）

```
收入来源1：会员订阅        → 家庭付费 39~99元/月
收入来源2：社区广告平台    → 商家CPM/CPC投放
收入来源3：社区消费分佣    → 家庭豆生态商户流水3~8%
```

### TV-001 家庭主页

**功能名称：** 家庭主页展示  
**优先级：** P0（MVP必须）  
**所属端：** Android TV APP  

**功能描述：**  
用户开机后进入家庭主页，展示家庭核心信息和功能入口，支持遥控器和语音控制两种交互方式。

**输入：**
- 用户登录状态（已登录/未登录）
- 家庭绑定信息
- 实时天气数据（第三方API）
- 家庭积分余额
- 今日任务列表

**输出：**
- 主页UI渲染（1920×1080分辨率）
- 家庭问候语（根据时段：早上好/下午好/晚上好）
- 天气信息（当前温度、天气状况、未来3天）
- 积分余额展示
- 功能入口导航
- 家庭成员头像

**页面布局：**
```
┌──────────────────────────────────────────────────┐
│  [家庭名称] 晚上好！       🌤️ 25°C  晴    [积分:1280豆]│
├──────────────┬───────────────────────────────────┤
│              │  📸 家庭照片轮播                  │
│  AI管家      │  (每5秒切换一张)                 │
│  入口        │                                   │
│  [语音唤醒]  ├───────────────────────────────────┤
│              │  今日任务                         │
│              │  ● 观看广告 +50豆  [未完成]       │
│              │  ● 签到      +5豆  [已完成 ✓]    │
├──────────────┴───────────────────────────────────┤
│  [AI管家] [积分中心] [广告大厅] [老人模式] [更多]  │
└──────────────────────────────────────────────────┘
```

**业务规则：**
- 未登录用户：显示游客界面，引导扫码登录
- 家庭照片：从家庭相册模块获取，最近30天照片优先
- 积分展示：实时读取，刷新频率10秒一次
- 语音唤醒词：「小智小智」或「你好智享」
- 遥控器上下左右：焦点导航
- 遥控器确认键：进入对应功能

**接口：**
```
GET /api/home/info
请求头：Authorization: Bearer {token}
返回：
{
  "family_name": "张家",
  "greeting": "晚上好",
  "weather": {"temp": 25, "desc": "晴"},
  "points": 1280,
  "today_tasks": [...],
  "family_photos": [...]
}

### TV-002 AI家庭管家

**功能名称：** AI智能对话助手  
**优先级：** P0（MVP必须）  
**所属端：** Android TV APP  

**功能描述：**  
基于大语言模型（LLM）的家庭AI助手，支持语音交互，提供日常问答、日程提醒、情感陪伴、儿童学习辅助、老人关怀等服务。

**输入：**
- 用户语音（麦克风采集）
- 文字输入（遥控器输入法）
- 家庭上下文（成员信息、日程、偏好）

**输出：**
- AI文字回复（屏幕显示）
- 语音合成播报（TTS）
- 执行指令（如：设置提醒、播放音乐、控制设备）

**对话场景分类：**

| 场景编号 | 场景名称 | 示例 | 处理方式 |
|----------|----------|------|----------|
| AI-S01 | 日常问答 | "今天天气怎么样" | 调用天气API |
| AI-S02 | 日程提醒 | "提醒我下午三点吃药" | 创建提醒任务 |
| AI-S03 | 儿童问答 | "什么是光合作用" | LLM儿童友好回复 |
| AI-S04 | 老人陪伴 | "我今天很孤独" | 情感陪伴LLM |
| AI-S05 | 家庭管理 | "帮我记录今天花了200块" | 写入家庭账本 |
| AI-S06 | 娱乐互动 | "讲个笑话" | LLM生成 |

**业务规则：**
- 唤醒后监听时间：10秒，超时自动关闭
- 老人模式：回复字号放大至36px，语速降低20%
- 儿童模式：过滤敏感词，启用儿童友好语言
- AI调用：优先使用DeepSeek API（低成本），备用OpenAI
- 每次对话消耗积分：0豆（免费，提高使用频次）
- 会员用户：对话次数不限
- 免费用户：每日20次基础对话

**接口：**
```
POST /api/ai/chat
{
  "session_id": "xxx",
  "message": "今天天气怎么样",
  "user_mode": "normal|elder|child",
  "context": []
}
返回：
{
  "reply": "今天晴天，气温25度，适合外出。",
  "tts_url": "https://...",
  "actions": []
}
```

### TV-004 广告大厅

**功能名称：** 用户主动观看广告获取积分  
**优先级：** P0（MVP必须）  
**所属端：** Android TV APP  

**功能描述：**  
提供用户自愿观看广告的入口。区别于传统强制广告，本功能为"福利广告"模式——用户主动进入广告大厅，选择感兴趣的广告观看，观看完成后获得积分奖励。

**页面结构：**
```
┌─────────────────────────────────────────────────────┐
│  广告大厅  今日已赚：120豆  今日上限：500豆          │
├──────────────────┬──────────────────────────────────┤
│  📦 [广告1]      │  📦 [广告2]                     │
│  XX超市          │  XX家政服务                     │
│  观看30秒得50豆  │  观看15秒得20豆                │
│  [立即观看]      │  [立即观看]                    │
├──────────────────┼──────────────────────────────────┤
│  📦 [广告3]      │  📦 [广告4]                     │
│  XX儿童英语      │  XX养老服务                     │
│  观看60秒得100豆 │  观看30秒得50豆                │
│  [立即观看]      │  [立即观看]                    │
└──────────────────┴──────────────────────────────────┘
```

**业务规则：**
- 广告展示：按家庭画像精准推送（年龄、地域、兴趣）
- 广告播放：全屏展示，不可跳过（用户自愿点击才播放）
- 播放进度：底部进度条，达到规定时长后自动结算积分
- 异常处理：播放中途退出，不结算积分
- 同一广告：每天只能获得一次积分
- 广告来源：优先本地社区商家，其次全国品牌

**积分结算流程：**
```
用户点击[立即观看]
    ↓
记录开始时间（服务端）
    ↓
播放广告视频
    ↓
播放完成（客户端回调）
    ↓
服务端验证播放时长
    ↓
通过验证 → 增加积分 → 弹出"恭喜获得XX豆"
失败验证 → 不结算 → 记录异常日志
```

# 六、家庭豆社区经济体系（核心升级方向）

## 6.1 核心理念

> **从"电视广告积分"升级为"社区数字消费货币"**

**V3.0家庭豆：**
```
看广告 → 获积分 → 抵扣会员费
（封闭循环，价值有限）
```

**V4.0家庭豆（社区经济版）：**
```
看广告/消费/活动 → 获家庭豆 → 兑换社区真实服务
（开放生态，价值倍增）
```

## 6.3 家庭豆流转机制

### 豆的产生（供给端）

| 来源 | 描述 | 每户月均获得 |
|------|------|-------------|
| 广告观看 | 主动看广告 | 约800豆 |
| 日常行为 | 签到/AI/照片 | 约200豆 |
| 邀请奖励 | 成功邀请一户+500豆 | 约100豆（均摊） |
| 社区活动 | 物业/平台发放 | 约100豆 |
| **月均总获得** | | **约1,200豆** |

### 豆的消耗（需求端）

| 消耗场景 | 换算 | 月均消耗 |
|----------|------|---------|
| 会员费抵扣 | 1,000豆/月（抵10元） | 约500豆 |
| 社区商品兑换 | 500-8,000豆/次 | 约400豆 |
| 视频平台权益 | 3,000豆/月 | 约300豆 |
| **月均总消耗** | | **约1,200豆** |

> **设计目标：** 豆的产生量 ≈ 消耗量，保持生态平衡，避免通胀。

## 6.4 商家接入模式

### 商家类型A：广告投放型

商家投入广告预算 → 用户看广告获豆 → 商家品牌曝光

```
商家充值：1000元广告费
→ 平台分发给用户：2000次×50豆/次观看
→ 商家获得：2000次精准曝光

## 9.3 投资人常见问题准备

**Q1：为什么老年用户会每天使用这个产品？**

A：因为子女付费+AI情感陪伴形成双重锁定。老人不会主动卸载软件，留存率是同类产品3倍。对比手机APP，电视大屏是客厅中心，老人每天在客厅的时间超过6小时。

**Q2：为什么商家愿意在这里投广告而不是美团/抖音？**

A：精准度不同。智享直接面向1-2公里内的家庭，是超本地化广告。商家付0.5-2元/次观看，ROI远高于信息流广告（通常每点击3-15元）。

**Q3：积分系统是否会造成平台财务压力？**

A：积分≠现金。设计上积分只能用于抵扣会员费（而非全额）、兑换合作商品（商家承担成本）、撬动用户留存。平台真实成本极低，积分通胀风险已通过每日上限和消耗场景平衡。

**Q4：护城河在哪里？**

A：三层护城河：①家庭数据（家庭画像比手机个人画像价值更高）；②社区商家网络（一旦建立替换成本极高）；③物业关系（物业成为分销渠道，竞对难以复制）。

# 十、核心竞争壁垒与估值逻辑

## 10.1 五层竞争壁垒

### 第一层：家庭入口垄断
```
电视大屏 × 客厅场景 × 家庭共同使用
→ 不同于手机（个人）、PC（工作）
→ 唯一占据"家庭共同注意力"的设备
```

### 第二层：老人用户高壁垒
```
老人学习新App成本极高（自然留存）
子女付费意愿强（情感驱动）
一旦建立习惯，流失率<5%/年
```

### 第三层：社区商家网络效应
```
商家网络 > 100家/城市 时：
→ 用户可选择兑换的商品足够多
→ 用户留存率显著上升
→ 更多用户 → 吸引更多商家 → 正向飞轮
```

### 第四层：家庭数据资产
```
家庭成员结构 + 消费偏好 + 健康数据 + 位置数据
= 商业价值远超个人数据（家庭决策权）
```

### 第五层：物业渠道壁垒
```
全国物业数量约40万家（10亿人口覆盖）
每个物业签约 = 锁定该小区几年
建立物业关系网络后，竞对进入成本极高
```
